# projet-chengdu-uestc
Projet de recherche et de développement matériel/logiciel réalisé lors de mon stage d'ingénierie à l'University of Electronic Science and Technology of China (UESTC) à Chengdu.

Ce dépôt regroupe les codes sources, les scripts de traitement et les fichiers de conception développés dans le cadre de mes travaux de recherche à l'UESTC (Chengdu, Chine).

Objectif : robot.

Matériel ciblé : Microcontrôleurs STM32 / ESP32-S3 /nrf52.

Outils & Langages : C/C++, Python, KiCad / EasyEDA Pro.
